# 🏀 NBA Daily Bot

Automated NBA newsletter sent daily via email with game results, top performers, and news.

## Features

- 📊 **Game Results** - Scores, records, and margins for all NBA games
- 👑 **Top Performers** - Top 3 players per winning team + best from losing team
- 🎯 **AI Summary** - Generated by Mistral-7B with Trashtalk-style commentary
- 📰 **Latest News** - NBA headlines from ESPN
- 📧 **Auto Email** - Sent daily at 7:15 AM Paris time

## Quick Start

### 1. Clone and Install

```bash
git clone https://github.com/justinmartin/nba_daily_bot.git
cd nba_daily_bot
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure Environment

Copy `.env.example` to `.env` and fill in:

```env
# HuggingFace API (for LLM)
HF_API_TOKEN=your_huggingface_token
MODEL_ID=mistralai/Mistral-7B-Instruct-v0.2:featherless-ai
HF_PROVIDER=featherless-ai

# Email (Gmail)
MAIL_SMTP_HOST=smtp.gmail.com
MAIL_SMTP_PORT=587
MAIL_SMTP_USER=your_email@gmail.com
MAIL_SMTP_PASSWORD=your_app_password
NEWS_RECIPIENT=recipient@email.com

# Optional
MAX_TOKENS=2000
BOT_RUN_TIME=07:30
```

### 3. Run

```bash
# Run once and send email
python run.py once

# Run scheduler (checks daily at configured time)
python run.py schedule
```

## GitHub Actions Setup

The bot runs automatically via GitHub Actions:

1. Add all environment variables as **Repository Secrets**:
   - `HF_API_TOKEN`
  - `MODEL_ID`, `HF_PROVIDER`, `USE_HF_INF_API`
   - `MAIL_SMTP_HOST`, `MAIL_SMTP_PORT`, `MAIL_SMTP_USER`, `MAIL_SMTP_PASSWORD`
   - `NEWS_RECIPIENT`
   - `MAX_TOKENS`, `BOT_RUN_TIME`

2. Workflow runs daily at **6:15 AM UTC** (7:15 AM CET / 8:15 AM CEST)

3. Manual trigger: GitHub Actions → NBA Daily Newsletter → Run workflow

## Data Sources

- **NBA Stats**: stats.nba.com via `nba-api` (no key required)
  - ScoreboardV2: Daily games
  - BoxScoreSummaryV3: Scores & team records
  - BoxScoreTraditionalV3: Player statistics
- **News**: ESPN NBA RSS feed
- **LLM**: Mistral-7B-Instruct via HuggingFace OpenAI-compatible API

## Troubleshooting

### 400 Bad Request from HuggingFace Router
- Use a provider-suffixed model in `MODEL_ID`, for example:
  `mistralai/Mistral-7B-Instruct-v0.2:featherless-ai`
- If `MODEL_ID` has no provider suffix, set `HF_PROVIDER` (default fallback is `featherless-ai`)
- Check GitHub Action secrets: `MODEL_ID`, `HF_PROVIDER`, `HF_API_TOKEN`

### "No module named 'pandas'" or "No module named 'nba_api'"
```bash
pip install -r requirements.txt
```

### "Read timed out" from stats.nba.com
The NBA API is slow. The bot has 60s timeouts and retry logic. Just wait - it will complete.

### Email not sending
- Use Gmail **App Password**, not your regular password
- Enable 2FA on Gmail first
- Check `MAIL_SMTP_USER` and `MAIL_SMTP_PASSWORD` in `.env`

### GitHub Actions failing
- Verify all secrets are set in repository settings
- Check workflow logs for specific errors
- Manual trigger available for testing
